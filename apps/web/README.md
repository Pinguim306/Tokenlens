# web

Frontend do Tokenlens (Next.js + Tailwind CSS).

Fase 0: layout base e tabela do screener com estado vazio, lendo a allowlist de `@tokenlens/registry`. As colunas de métricas (preço, volume, liquidez, holders, tx) são ligadas à API do indexer nas Fases 2–3.

```bash
pnpm dev   # http://localhost:3000
```
